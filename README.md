# RentalCo · clickable prototype

Prototype for my Cityfurnish UI/UX Design Intern assignment. RentalCo is a fictional furniture rental brand.

Flow: product page → add the chair → cart → delivery date (with a "date just got full" failure state) → review & pay → done.

Single `index.html`, no build step. Designed by Shivansh Sharan Nigam.
